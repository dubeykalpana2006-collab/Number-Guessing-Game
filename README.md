# Number Guessing Game 🎮

A simple Number Guessing Game made using Python.

## Features
- Easy difficulty (1–50, 10 attempts)
- Medium difficulty (1–100, 7 attempts)
- Hard difficulty (1–500, 5 attempts)
- Random secret number generation
- Too High / Too Low hints
- Limited attempts
- Game Over message

## Technologies Used
- Python
- NumPy

## How to Run

```bash
pip install numpy
python number_guessing_game.py
```
